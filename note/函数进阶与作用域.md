## 一.*args 和 **kwargs 的使用
  args和kwargs是对这两者的名称描述，不是函数本身，本身是*和**这两个符号。
  这两者是Python中用于定义可变数量参数的语法，允许函数接收非定长度的参数列表。

其中：*(arguments)用于接收任意数量的位置参数，在函数中，这些参数会被打包成元组（tuple）进行访问
**（keyword argument）用于接收任意数量的关键字参数，在函数中，这些参数会被打包成字典（dict），其中key是参数名，values是对应的参数值

实际使用案例：
```python
# encoding=utf-8
def func(a,b,*args,**kwargs)
    print(f"a:{a},b:{b}")
    print(f"args:{args}")
    print(f"kwargs:{args}")
print(func(1,2,3,4,x=10,y=20))
```
这行代码最终输出为 a:1,b:2,args:(3,4),kwargs:{'x':10,'y':20}
*注意，实际使用时，参数定义args必须在kwagrs之前。*

## 二.解包（unpackaing）
  解包是args和kwargs的逆操作，即“把元组拆成位置参数”，“把字典拆成关键字参数”
  还是使用符号*和**实现。

代码案例：
``` python
#encoding =utf-8
def add(a,b,c)
    return a+b+c
nums=[1,2,3]
print(add(*nums)) #输出6
kwnums={'a':10,'b':20,'c':30}
print(add(**kwnums)) #输出60
```

从以上例子可以理解为：* 是“位置参数函数”，**是“关键字参数函数”
*注：带args的函数，如果新增了位置参数，极其容易出错而且不容易排查，不推荐广泛使用*

## 仅限关键字参数（keyword-ONLY-argument）
  在函数参数列表中，使用一个* 来分割“位置参数”和“关键字参数”，在* 之后的都必须是关键字参数。
  在关键字参数中，必须使用“关键字=值”的形式传递参数，而不能只给一个值。

代码示例：
```python
#encoding=utf-8
def query_users(lim,offset,*,min_fo,include): #这里*之后的就全部都是关键字参数
    pass
print(query_users(20,0,min_fo=100,include=True)) #如果直接写成(20,0,100,True),会报错typeerror
```
为什么要有这个参数？
1.增强可读性：这个方法很好的将两种参数分到两边，如果一个函数包含很多参数时，这种方法可以让使用者直接抓住重点理解。
2.增强函数稳定性：在需要拓展函数时，增删或重命名仅限关键字参数不会影响旧代码
3.与* 配合使用：在函数中有*args时，* 后面的参数就会被默认为关键字参数，不需要**。

## 默认参数的陷阱
  Python函数的默认参数值在函数定义时只被计算和创建一次，而后的每一次对该函数的调用都会重复调用同一个对象。
  这就导致了每一次输出都可能会被上一次函数调用污染。
  *注：这个陷阱只适用于可变对象（列表，字典，集合），而不可变对象（数字，元组，字符串）不会受影响*

代码案例：
```python
def add(item,ls=[]):
    ls.append(item)
    return ls
print(add(1)) #第一次调用，输出[1]
print(add(2)) #第二次调用，函数会调用第一次调用后的函数，这时会输出[1,2]，我们期望的是只输出[2]
```
改进方法：
  将默认值设为None，在函数内部增加初始化模块

代码案例：
``` python
def add(item,ls=None): #定义为None，表示这里只是声明有ls这个变量，ls的真正赋值在函数体内，而不在函数定义
    if ls is None:   #注意对于布尔值只能用is 不能是运算符
        ls=[]   #如果直接定义为空列表，那么函数只会生成一次空列表，此后的操作都只是在调用这个列表，而不是生成新的
    ls.append(item)
    return ls
```


## 闭包（closure）与作用域
### 作用域规则（LEGB）
- L(local)：当前函数、类方法的作用域
- E(encoding)：任何外围（嵌套）函数的局部作用域
- G(global)：当前模块的全局作用域
- B(built-in)：Python的内置作用域
上面这四条，是按照如上顺序查找的。
### 闭包（closure）
  闭包是一个出现在嵌套函数中的概念：
  对于在嵌套函数内部的函数，这个函数“记住”了定义在外围作用域中的变量，即使是外围函数已经执行完毕。
  注意：*这个函数记住的是变量本身，而不是变量某一时刻赋的值，所有闭包最终都会引用同一个循环变量，并且都只共享最终值，这个特性叫“延迟绑定”，以及在闭包中赋值无法改变外部变量，因为Python默认：在一个作用域内对变量赋值，会将其解释为在该作用域的局部变量*

代码案例：
```python
def outer():
    msg=1
    def inner():  #这个inner函数就是一个闭包
        print(msg) #这里inner调用了外围函数的变量msg
    return inner
my_func=outer()
print(my_func)
```

### 延迟绑定
```python
funcs=[]
for i in range(3):
    funcs.append(lambda:i) #这里的lambda：i也是一个闭包，for循环创造了3个闭包，每一个都引用了外围变量i
for f in funcs:
    print(f(),end=" ") #这里三个函数储存的都是最终值2，所以输出[2 2 2]
```
修复方法是：
  通过默认参数来固定当前值
```python
funcs=[]
for i in range(3):
    funcs.append(lambda i=i: i) #这里把当前值i作为默认参数传入
```

## nonlocal关键字
  正如我们在闭包中描述的，“赋值即定义”：
  *如果在嵌套函数中直接给某变量赋值，Python会视其为该嵌套函数内的局部变量，从而无法修改外层函数的同名变量*
  nonlocal关键字解决了这个问题，在变量前声明nonlocal，即说明“该变量是外围作用域的变量，可以进行修改”

代码示例：
``` python
def outer():
    count=0 #这里count是外围变量
    def inner():
        nonlocal count #在闭包内声明count是外围变量
        count +=1 #开始修改
        print(count)
    inner() #输出1
    inner() #输出2
print(outer())
```
关于nonlocal，一些注意事项：
- nonlocal不等于global，从LEGB规则，global对应G级，nonlocal对应E级
- 在实际使用中，过度使用nonlocal容易导致代码难以追踪，如果函数比较复杂，不推荐使用。
